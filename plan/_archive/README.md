# 보관 원문 안내

이 디렉토리는 과거 계획의 원문과 승계 증거를 보존한다. 원문 내부의 상대 링크·일정·명령은 작성 당시 위치와 상태를 기준으로 하며 현행 실행 기준이 아니다. `INDEX.md` 역시 과거 원문이다. 현재 작업은 [ECU 계획](../ECU.md), [IVI 계획](../IVI.md), [공동 규약](../detail/common/00_협업_규약.md)을 따른다.

## 옛 IVI 원문의 문서 링크 대응

2026-09-09 Markdown 렌더링 후 확인한 `IVI.md`의 끊긴 로컬 링크는 5개다. 기존 검토의 6건이라는 수치와 달리 현재 파일에서는 아래 5개가 확인됐다. 원문 바이트와 해시를 보존하기 위해 해당 링크는 수정하지 않았으며 아래 대체 링크로 이동한다.

| 원문의 상대 경로 | 현재 문서 |
|---|---|
| `docs/ICD.md` | [ICD](../../docs/ICD.md) |
| `docs/SDD-ECU.md` | [SDD-ECU](../../docs/SDD-ECU.md) |
| `docs/SDD-IVI.md` | [SDD-IVI](../../docs/SDD-IVI.md) |
| `docs/TARA.md` | [TARA](../../docs/TARA.md) |
| `docs/TEST_PLAN.md` | [TEST_PLAN](../../docs/TEST_PLAN.md) |

원문·승계 과제의 경로와 해시는 [manifest](plan_20260908/manifest.json), 통합 당시 기록은 [정리 이력 Part 4](../../docs/development/reviews/정리_이력.md#part4-planmerge)에 있다. 현행 문서의 변경으로 과거 보관본의 동작·내용을 재검증한 것으로 취급하지 않는다.
