## 3. 수행 절차

### 3.1 데모 시나리오 A — 정상 동작

```bash
./adaptive_ecu/build/adaptive_ecu --interface can0 --secoc on --sensor-mode profile_csv
```

- [ ] Node B 대시보드에 SOC / SOH / 전압 / 전류 / 온도 실시간 표시
- [ ] SOC 15% 부근 → **WARNING** 표시 (`0x101` Reason `0x01`)
- [ ] SOC 3~4.5% → **CRITICAL** 표시 (`0x101` Reason `0x02`)
- [ ] `0x100`, `0x101`, `0x102`, `0x103` candump 증적 저장

```bash
candump -t a -l can0     # candump-*.log 파일로 저장됨
```

**상태 전이를 데모에서 유도하는 방법** — 두 경로가 있다.

```bash
# 주 경로: ADS1115 가변저항으로 팩 전압을 42.0V -> 30.8V로 낮춘다
./adaptive_ecu/build/adaptive_ecu --interface can0 --secoc on --sensor-mode ads1115
```

```bash
# 백업 경로: 전압 램프 프로파일 재생 (하드웨어 장애 시)
./adaptive_ecu/build/adaptive_ecu --interface can0 --secoc on     --sensor-mode profile_csv --profile adaptive_ecu/data/failsafe_demo.csv
```

| 팩 전압 | 수렴 SOC | 상태 |
|---:|---:|---|
| 42.0V | 100% | NORMAL |
| 34.2V | 19.9% | **WARNING** |
| 31.3V | 5.0% | **CRITICAL** |

두 경로의 구현·생성 절차는 [M3](M3_EKF_Failsafe_SecOC.md) 3.11·3.12에 있다.

> `--soc=19`, `--sensor-mode potentiometer`는 **동작하지 않는다.** `main.cpp`가 받는 인자는 `--interface`, `--sensor-mode`, `--profile`, `--secoc`, `--key` 뿐이고, `potentiometer` 모드는 값 주입 경로가 없어 기본값만 반환한다.

### 3.2 데모 시나리오 B — 공격과 방어

세 단계를 순서대로 보여준다. 각 단계 사이에 이전 프로세스를 반드시 종료한다.

시연 전 [공동 발표의 시연 준비·구성 전환](../common/03_발표_제출.md)을 따른다. 양측 방어 설정, 이전 프로세스 종료, 정상 송신 복구와 입력·관측 조건을 먼저 확인한다.

```bash
# 1) 무방어 — 가짜 SOC가 대시보드에 그대로 표시된다
./adaptive_ecu/build/adaptive_ecu --interface can0 --secoc off &
ECU_PID=$!
python security/attacks/spoofing_attack.py --channel can0 --count 5
kill $ECU_PID
```

```bash
# 2) SecOC 방어 — 위조값은 반영하지 않고 정상 인증값은 계속 갱신한다
./adaptive_ecu/build/adaptive_ecu --interface can0 --secoc on &
ECU_PID=$!
python security/attacks/spoofing_attack.py --channel can0 --count 5
kill $ECU_PID
```

```bash
# 3) IDS 탐지 — 0x200 경보가 AlertBanner로 뜬다
./adaptive_ecu/build/adaptive_ecu --interface can0 --secoc on &
ECU_PID=$!
python security/ids/realtime_ids.py --channel can0 &
IDS_PID=$!
python security/attacks/flooding_attack.py --channel can0 --duration 5
kill $ECU_PID $IDS_PID
```

- [ ] 2)에서 주입한 위조값이 반영되지 않고 정상 인증값은 계속 갱신되는지 수신·인증·UI 기록으로 확인한다. raw-only 주입의 교체·만료·인증 미성립과 실제 MAC 불일치를 구분하며, `ERR_HMAC_VERIFY_FAIL`을 필수 로그로 요구하지 않는다.
- [ ] 3)에서 공격 시작부터 AlertBanner 표시까지 3초 이내인지 확인 (TC-INT-004). TC-PERF-003은 해당 `0x200` 수신까지 별도 기록한다.
- [ ] 각 단계 화면과 로그를 촬영한다

> `spoofing_attack.py`, `flooding_attack.py`, `realtime_ids.py`는 [M4](M4_IDS_공격_물리통합.md) 3.5에서 만드는 최소 실시간 경로 산출물이다. 없으면 데모 B를 실행할 수 없다.

### 3.4 ECU 발표 슬라이드

| 슬라이드 | 핵심 메시지 | 증적 |
|---|---|---|
| BSW / CAN CDD | SocketCAN raw socket으로 CDD 계층 구현, `CanDriver` 추상화로 Mock 교체 가능 | TC-BSW 통과 결과 |
| BMS / EKF | EKF SOC 추정, 쿨롱 카운팅 대비 RMSE 비교 | `results/ekf_accuracy.png` |
| Fail-safe | 4상태 7사유 전이, 브랜치 커버리지 | lcov 리포트 |
| SecOC | Python 프로토타입 → C++ 이식 → IVI verifier 교차 검증 | 테스트 벡터, `test_secoc` 결과 |
| IDS | 7차원 특징, 규칙·사양기반·Isolation Forest 비교 | `run_eval.py` 출력 |
| Ablation | 3 Config × 4 Attack × 100회 | `results/ablation_*.png` |

**토킹 포인트 작성 규칙**

- 수치는 실행 결과에서 인용한다. 슬라이드에 적기 전에 원출력과 대조한다
- 합성 데이터 기반 수치에는 그 사실을 말로 붙인다
- 미달 항목은 슬라이드에서 빼지 말고 "현재 x%, 원인 y"로 말한다
- 탐지율 목표 ≥90%·오탐률 목표 ≤5%와 실측값을 구분한다. 두 비율 자체의 단위는 %이며 재현성 차이의 %p와 혼용하지 않는다.

### 3.7 예상 질문 대비

| 질문 | 답변 핵심 |
|---|---|
| EKF 파라미터를 어떻게 정했나 | 초기값은 Config 기본값, R→Q 순으로 조정. 최종값과 근거는 SDD-ECU에 기록 |
| OCV 모델과 실제 배터리의 관계는 | 목표는 SDD의 가상 10직렬·50Ah/3차 모델. 현 구현 차이·적용 근거·독립 정확도 평가를 구분해 답한다 |
| MAC 4바이트로 충분한가 | CAN DLC 8바이트 제약. 위조 기대시간은 `measure_can_secoc.py`의 계산값을 인용 |
| IDS 오탐률 관리 방법 | ROC 동작점에서 임계 선택, 목표 TPR≥90% / FPR≤5%. 재현성 차이의 %p와 구분 |
| 왜 규칙 베이스라인도 두었나 | ML의 필요성을 정량 비교하기 위해. masquerade에서 차이가 드러난다 |
| 재현성은 어떻게 보장했나 | seed 고정(42), `RANDOM_STATE=42`, CPU governor 고정, 재실행 편차 ≤5%p 검증 |
| 합성 데이터의 한계는 | 실 차량 트래픽이 아니며, 결론의 적용 범위를 그만큼 좁게 말한다 |

## 4. 검증 명령과 합격 기준


## 5. 실패 시 대응과 우회

**데모 중 CAN 하드웨어 실패** — `vcan0` 경로로 즉시 전환한다. 전환했음을 발표에서 밝힌다.

**공격이 탐지되지 않음** — 리허설에서 찾은 안정 구간(강도·지속시간)을 그대로 쓴다. 그래도 실패하면 백업 영상으로 넘어가고, 원인은 Q&A에서 설명한다.

**Node B 준비 미완** — ECU 단독으로 `candump` 출력을 보여주는 축소 데모를 준비한다. 대시보드 부분은 영상으로 대체하고 그 사실을 밝힌다.

**시간 초과** — ECU 파트는 5~7분 목표다. 슬라이드 6장 중 Ablation과 SecOC를 우선으로 남기고 나머지를 압축한다.
