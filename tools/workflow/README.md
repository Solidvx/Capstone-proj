# 운영 도구 구현 골격

core.py는 공통 검사, check.py는 CLI, mcp_server.py는 연결부, tests/는 도구 자체 검증 위치다. 현재 세 Python 파일은 직접 실행 시 미구현 오류로 종료한다. 자동 수정·서버 연결·제품 실행은 없다. 기존 security 의존성에 운영 도구 의존성을 섞지 않는다.

현재는 목적 안내만 작성했다. 실제 작업을 시작할 때 관련 계획 과제·공식 원본 경로·담당·입력·결과·증거를 기입한다. 비밀이나 실제 자격 증명은 넣지 않는다.
