# 운영 도구 시험 위치

공통 로직·CLI·MCP의 정상/실패/미실행 및 경로 이탈·입력 오류·판정 일치 시험을 구현할 위치다. 현재 실행할 테스트는 없다. 빈 테스트 모음을 제품 통과로 표시하지 않는다.

현재는 목적 안내만 작성했다. 실제 작업을 시작할 때 관련 계획 과제·공식 원본 경로·담당·입력·결과·증거를 기입한다. 비밀이나 실제 자격 증명은 넣지 않는다.
