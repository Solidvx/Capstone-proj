# Capstone 작업 기록 연결

프로젝트 전용 참조 안내다. 공통 정책 원본은 [AGENTS](../../../AGENTS.md), 절차 원본은 [루트 SKILL](../../../SKILL.md)이며 도구별 CODEX.md 또는 CLAUDE.md도 따른다. 이 문서는 기존 지침을 대체하거나 추가 권한을 부여하지 않는다.

작업 시작·재개 시 [workflow](../../../docs/development/workflow.md)에서 작은 변경과 다단계 기록 방식을 선택하고 [운영 인덱스](../../../docs/development/README.md)에서 필요한 분야만 읽는다. 실제 요청에 해당하는 작업 기록을 찾고 원본 상태·판단·증거와 현재 파일을 대조한다. 여러 작업 중 임의의 상태를 갱신하지 않는다.

공식 계약·요구·시험은 기존 docs/를 참조하고 코드는 기존 제품 경로에서 관리한다. 원본 전체를 작업 폴더에 복제하지 않는다. [AIdlc 안내](../../../docs/aidlc/README.md)에 따라 필요한 산출물만 생성한다.

현재 CLI·MCP·hook 자동화는 미구현이다. [tooling](../../../docs/development/tooling.md)의 실제 배치·연결 상태를 확인하고 제공되지 않는 도구를 호출했다고 설명하지 않는다. 이 파일의 배치만으로 자동 로딩 성공을 주장하지 않는다.
