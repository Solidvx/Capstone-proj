# Claude commit 진입 문서

[공통 commit 절차](../../../.agents/skills/commit/SKILL.md)를 읽고 STEP 1~7을 적용한다. 그 절차가 연결하는 [커밋 규칙](../../../.agents/skills/commit/rules.md)이 양측 공통 원본이다. 이미 읽고 변경되지 않은 원본은 재사용한다.

공통 정책은 [AGENTS](../../../AGENTS.md), 도구별 안내는 [CLAUDE](../../../CLAUDE.md)를 따른다. 이 파일은 절차를 복제하거나 실행 권한을 추가하지 않는다. 상세한 사람용 설명이 필요할 때만 [매뉴얼](../../../docs/development/governance/commit.md)을 읽는다.
