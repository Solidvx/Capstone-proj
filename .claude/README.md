# Claude 설정 골격

settings.json은 빈 JSON 객체로 생성했다. JSON에는 표준 주석을 넣을 수 없어 생성·사용 목적을 이 문서에 기록한다. 이 파일은 hook·권한·명령을 등록하지 않는다. 상속된 사용자 설정을 비활성화하는 의미도 아니다. 후속 구현에서 지원 이벤트와 설정 형식을 확인한 뒤 구성한다. 기존 skills/ 참조 문서는 유지한다.

현재는 목적 안내만 작성했다. 실제 작업을 시작할 때 관련 계획 과제·공식 원본 경로·담당·입력·결과·증거를 기입한다. 비밀이나 실제 자격 증명은 넣지 않는다.
