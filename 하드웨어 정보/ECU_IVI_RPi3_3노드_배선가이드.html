ECU · IVI · 공격 Pi3 / 조립 순서표

한 번에 한 선씩.
왼쪽에서 오른쪽으로 연결하세요.

전체 회로를 외울 필요 없습니다. 아래 순서대로 연결하고, 각 단계 끝에서 확인하세요.

시작 전: 세 라즈베리파이의 전원을 모두 뽑으세요.
ECU·IVI의 새 CAN 보드는 40핀에 꽂으면 MOSI·MISO·SCK가 연결됩니다. 별도 신호 점퍼선은 공격 Pi3에만 필요합니다.

핀 번호는 모두 물리 핀 번호입니다. 보드의 pin 1 표시를 먼저 찾으세요. 아래 상자는 연결 관계이며 실제 단자 위치 그림이 아닙니다.

① ECU② IVI·화면③ CAN 연결④ 공격 Pi3⑤ 최종 확인
STEP 01

ECU에 새 보드 두 개 꽂기

E3P에 CAN 보드와 ADS1115를 연결합니다. 이미 꽂았다면 방향과 간섭만 확인하세요.

ECU Pi4 → E3P → CAN 보드 + ADS1115
이 단계는 40핀 커넥터 연결입니다. MOSI·MISO·SCK 점퍼선을 따로 꽂지 않습니다. E3P의 포트 위치·장착 방향은 실물 표시로 확인해야 합니다.
STEP 02

가변저항 세 선 연결하기

한 줄씩 연결하세요. 전원 두 선은 GPIO 헤더, OUT은 ADC 입력으로 갑니다.

가변저항VCC
→
ECU 쪽 GPIO 헤더1번 · 3.3V
가변저항GND
→
ECU 쪽 GPIO 헤더6번 · GND
가변저항OUT
→
ADS1115 나사 단자AIN0 / A0
E3P 또는 ADS1115에 노출된 동일 번호의 GPIO 헤더에서 3.3V·GND를 꺼내도 됩니다. OUT은 40핀이 아니라 AIN0 나사 단자에 넣습니다. 피복을 벗긴 끝을 고정하고 흰색 Grove 커넥터는 비워 둡니다.
STEP 03

IVI에 CAN 보드 꽂기

IVI Pi4의 40핀 헤더에 두 번째 SEENGREAT CAN 보드를 장착합니다.

IVI Pi4 → CAN 보드
IVI에는 E3P·ADC·레벨 변환기가 필요 없습니다. CAN 보드를 꽂은 40핀으로 전원과 SPI 신호가 함께 연결됩니다.
STEP 04

IVI 화면 연결하기

화면은 리본 케이블 1개와 전원선 2개를 연결합니다. 브레드보드는 생략해도 됩니다.

화면 쪽은 기존에 정상 작동했던 전원 배선을 유지하세요. 3핀 커넥터의 정확한 핀 배열은 아직 미확인입니다. 하우징 전체를 임의의 세 핀에 꽂지 않습니다. 별도 1열 핀은 위 번호로 세지 말고 5V·GND 인쇄 표시를 확인하세요.
화면의 리본은 CAN 보드가 아니라 Pi 본체의 DISPLAY 포트에 연결합니다. 4번·6번은 화면 전원용입니다. CAN 단자의 PGND는 쓰지 않습니다.

STEP 09

전원 켜기 전에 마지막 확인

배선 완료와 통신 성공은 다릅니다. 마지막 점검 후 소프트웨어 설정으로 넘어갑니다.

  • 노출된 금속선·단자·보드가 서로 닿지 않는가?
  • 전원을 모두 뺀 상태에서 H–L 저항이 약 60Ω인가? 약 40Ω이면 종단저항 세 개가 켜졌는지 확인합니다.

SPI·INT 점퍼선 직접 연결

“MOSI, MISO, SCK는 안 연결해도 되나요?”

ECU·IVI에서는 40핀에 보드를 꽂는 순간 내부 배선으로 연결됩니다. 외부에 점퍼선이 없어도 해당 GPIO는 사용 중입니다. 기존 모듈을 쓰는 공격 Pi3만 신호선을 한 가닥씩 연결합니다.

02

ECU — E3P · CAN · ADC · 가변저항

  1. Pi4의 40핀을 E3P에 연결하고, E3P의 분배 커넥터에 CAN 보드와 ADS1115를 연결합니다.
  2. 각 커넥터의 물리 pin 1을 맞춥니다. E3P는 같은 핀을 분배하며 포트마다 GPIO 번호가 새로 생기지 않습니다.
  3. 가변저항의 VCC·GND·OUT을 아래 표대로 연결합니다.
가변저항연결 목적지직접 연결할 선
VCCECU 쪽 3.3V · 물리 1 또는 173.3V 전원선
GNDECU 쪽 GND · 예: 물리 6접지선
OUTADS1115의 AIN0 / A0 나사 단자아날로그 신호선 — 40핀 GPIO에 꽂지 않음
ADS1115 쪽 헤더에서 전원을 꺼내도 같은 ECU의 3.3V·GND로 이어진 핀이면 됩니다. AIN0 나사 단자는 피복을 벗긴 전선 끝을 고정합니다. 옆 CAN 보드에 금속이 닿지 않게 하고, 흰색 Grove 커넥터는 이번 배선에서 비워 둡니다. 입력은 0~3.3V이며 가상 배터리의 30~42V를 실제로 넣지 않습니다.
E3P와 ADS1115 확인 사항

E3P 실물의 방향·연속성·장착 간섭은 아직 확인 대상입니다. 무리하게 보드를 쌓지 마세요. 기존 ADC는 분리하고 새 ADC만 주소 0x48로 사용합니다. SDA=물리3/BCM2, SCL=물리5/BCM3이며 헤더로 연결됩니다.

P11·P6은 보드 스위치의 wiringPi 이름입니다. 물리 11번·6번 핀을 뜻하지 않습니다.

03

IVI — CAN 보드와 공식 7인치 터치 화면

화면은 DSI 리본 1개 + 전원선 2개로 연결합니다. HDMI 케이블은 사용하지 않습니다.

출발도착연결 방법
IVI Pi의 DISPLAY / DSI 포트화면 보드의 DSI 포트리본 케이블. CAMERA 포트와 혼동하지 않기
표준 40핀 확장부 물리 4번 · 5V화면의 5V 전원직접 전원선 연결. 물리 2번도 5V지만 여기서는 4번 사용
표준 40핀 확장부 물리 6번 · GND화면의 GND직접 접지선 연결. CAN PGND 사용 금지

브레드보드를 꼭 거쳐야 하나요?

아니요. 이 그림은 5V·GND를 화면에 직접 연결하는 구성입니다. 기존 브레드보드로 같은 두 전원을 분배해도 되지만 필수는 아닙니다. Pi는 USB-C로 전원을 공급하고 화면에 별도 전원 어댑터를 동시에 연결하지 않습니다.

핀 번호는 “표준 40핀”에서만 그대로 셉니다.

보드 옆 별도 1열 핀을 40핀처럼 세지 마세요. 실제 5V·GND 인쇄 표시와 일치하는지 확인합니다. 사용자가 설명한 3핀 전원 커넥터의 정확한 형식과 화면 세대는 미확인입니다. 화면 쪽은 기존 정상 작동 배선을 유지하고, 3핀 하우징을 임의의 연속 3핀에 꽂지 않습니다.

04

공격 Pi3 — 기존 MCP2515를 옮기는 곳

기존 모듈이 5V MCP2515/TJA1050 + 8MHz 크리스털인 구성입니다. 실물의 전원·단자·8.000 표기를 먼저 확인합니다. 변환기 링크는 유사 제품이므로 실제 LV/HV 실크를 우선합니다.

① 먼저 전원선

Pi3 출발 핀도착
물리1 · 3.3VLC1 LV와 LC2 LV
물리2 · 5VLC1 HV, LC2 HV, MCP VCC
물리6 · GNDLC1 GND, LC2 GND, MCP GND

이 노드는 연결 대상이 많으므로 브레드보드의 전원 레일로 분배해도 됩니다. 3.3V 레일과 5V 레일을 분리하고 GND는 같은 Pi3 기준으로 묶습니다. 레일 중간 단절 여부는 전원을 뺀 상태에서 확인합니다.

한 행에 점퍼선 두 가닥입니다. 예: Pi3 물리23 → LC1 LV1, LC1 HV1 → MCP SCK. LV1과 HV1 사이를 직접 점퍼선으로 연결하지 않습니다. 변환기 내부가 신호 전압을 변환합니다. LC2의 나머지 신호 채널은 비워 둡니다.

LV/HV는 전원 단자이고, LV1/HV1처럼 숫자가 붙은 단자는 신호 단자입니다. 5V 쪽 MISO·INT를 Pi GPIO에 직결하지 않습니다. 공격 노드 MCP의 종단저항은 OFF입니다.

06

세 노드를 CAN H/L 두 선으로 연결

  1. ECU CAN0 H ↔ IVI CAN0 H, ECU CAN0 L ↔ IVI CAN0 L을 연결합니다.
  2. 같은 H/L 주 배선에서 공격 MCP의 H/L로 짧게 분기합니다. 긴 별 모양 배선은 피합니다.
  3. ECU와 IVI는 종단저항 ON, 공격 MCP는 OFF로 둡니다.
노드사용 단자종단저항
ECU SEENGREATCAN0 H / L120R 쪽 · ON
IVI SEENGREATCAN0 H / L120R 쪽 · ON
공격 MCP2515H / LOFF · 모듈의 점퍼/스위치 확인
SEENGREAT의 120R 방향 찾기: 초록색 나사 단자들이 위로 오도록 봤을 때 CAN0 옆 스위치의 위는 120R(ON), 아래는 NC(OFF)입니다. 실제 인쇄 표시를 우선하세요. 제조사 위치 그림의 ④가 CAN0 종단저항 선택입니다.
CAN 단자의 PGND는 Pi GPIO GND가 아닙니다.

이번 구성에서는 새 CAN 보드의 PGND를 비워 둡니다. 세 노드의 5V나 GND를 CAN 단자에 추가로 연결하지 않습니다. CAN1·RS485·외부 DC 입력도 사용하지 않습니다.

전체 전원을 뺀 상태에서 H–L 저항을 측정하면 두 120Ω이 병렬인 약 60Ω이 예상됩니다. 약 40Ω이면 종단저항 세 개가 켜졌는지 확인합니다. 이 저항값만으로 모든 배선의 정상 동작이 보증되지는 않습니다.

하드웨어 배선이 끝나도 CAN 설정은 필요합니다

부팅 설정 파일은 OS에 따라 /boot/firmware/config.txt 또는 /boot/config.txt입니다. 기존 CAN overlay를 확인해 해당 설정을 교체하고 중복 추가하지 않습니다.

ECU Pi4
dtparam=spi=on
dtparam=i2c_arm=on
dtoverlay=mcp2515,spi0-1,oscillator=16000000,interrupt=25
IVI Pi4
dtparam=spi=on
dtoverlay=mcp2515,spi0-1,oscillator=16000000,interrupt=25
공격 Pi3 · 8MHz 확인 후
dtparam=spi=on
dtoverlay=mcp2515,spi0-0,oscillator=8000000,interrupt=25

ECU의 현재 ADC 코드는 I²C 장치를 직접 사용하므로 dtoverlay=ads1115는 추가하지 않습니다. 공격 노드에서 기존에 검증한 SPI 속도 제한이 있으면 유지합니다.

재부팅 후, 송신 프로그램이 종료된 준비 상태에서 각 노드에 적용합니다.

sudo ip link set can0 down
sudo ip link set can0 up type can bitrate 500000
ip -details -statistics link show can0
candump can0

can0가 없거나 bus-off·오류 증가가 있으면 실험으로 넘어가지 말고 해당 노드의 설정·배선을 확인합니다. ECU → IVI 정상 수신부터 검증하고 Pi3는 수신부터 확인합니다.
