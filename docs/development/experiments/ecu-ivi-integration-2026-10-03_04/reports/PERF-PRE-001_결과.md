# PERF-PRE-001 예비 계측 결과

004 결과 archive를 tmp/perf-pre-001-received에 경로 이탈·링크를 차단하여 추출했다. 원본은 보존했다. 포함된 manifest는 기존004 manifest와 일치한다. 실행 환경/CTest는 담당자 보고 기준 12통과·1skip·0실패다.

## 결과

- [CSV 분석](../analysis/perf-pre-001-analysis.json): 300개 FRAME_SWAPPED, NOT_RENDERED 0, INDETERMINATE 0, 미확정 PENDING 0. 실제 run/boot 식별자 존재. 중복stage·완료frame ID·시각역전 없음.
- T1→T4 Qt proxy 평균 8.943716ms, 최대 66.210985ms, p99 15.303722ms. 물리 픽셀 표시 지연이 아니다. 300표본으로 공식 1,000표본 요구를 충족하지 않는다.
- [교차 분석](../analysis/perf-pre-001-crosscheck.json): CAN 1,200프레임, IVI 602프레임. IVI 전602행은 CAN 앞602행과 순서·payload 완전 일치. IVI가 목표 달성 후 먼저 종료해 CAN 수집만 계속된 꼬리598행을 IVI 수신 손실로 세지 않는다.
- BMS 600개/599간격: 최소99.680ms, 평균100.085043ms, 최대100.506ms. 관측 간격은 모두90~110ms.
- IVI BMS301개 중 정상 인증300개, MAC_FAIL1개. 따라서 수신 로그 내부에서 프레임 누락은 관측되지 않았지만 정상 입력 전체의 인증 성공은 아니다. CSV는 인증된 표본만 기록하므로 이 실패가300개 지연 통계에 나타나지 않는다.

## 이상 프레임과 보류 판정

수신 로그 0기준83행, CAN 0x102 payload `0755607600000052`, counter82에서 MAC_FAIL. 전후 counter는40→82→42다. 이 구간은 제공된 CAN 원본에도 동일하므로 앱 로그만의 문자열 오류로 설명하지 않는다. 원인은 아직 미확정이다. 개입 시험·다른 송신기·송신 경로/수집 자료의 문제를 증거로 구분해야 하며 특정 원인을 단정하지 않는다. 키 원문은 요청하지 않는다.

예비 결과는 “계측300표본 수집 성공, 지연 수치 목표 이내, 정상 인증 실패1건 조사 필요”다. 공식 성능 시험으로 넘어가기 전 해당 프레임 발생 경위를 확인하고 깨끗한 정상 구간을 새run으로 재수집한다. 기존 실패행을 지우거나 제외하여 기존 실행을 정상PASS로 바꾸지 않는다.

## ECU 출력의 한계

사용자 로그에는 시작·정상 stop 출력, 보고된 CAN 오류·drop·bus-off0, 최종TX12480이 있다. can-before 원본은 이번 archive에 없으므로 시험별TX차이는 확정하지 않는다. exit.txt 저장 명령을 두 번 실행하여 첫 종료코드가 후속 ip 명령의0으로 덮어써졌다. 현재 exit_code=0은 timeout/ECU 종료코드의 유효 증거가 아니다. 재실행 때는 종료코드 저장을 한 번만 수행하고 변수에 즉시 보존한다.

다음은 시험 중 의도적인 변조·다른 송신 실행 여부 확인 및 ECU측 실행 프로세스/원본 사전통계 확보다. 004 분석기와 관측 정상 주기 자체의 결과는 보존하며 IF 보류도 유지한다.

## 운영자 후속 확인

ECU 사용자는 안내된 정상 송신 외 다른 송신·변조 도구를 실행하지 않았다고 답했다. IVI 담당자는 빌드·CTest·대시보드·candump만 실행했고 의도적인 MAC 변조 절차는 없었다고 답했다. 이전부터 남아 있던 송신 프로세스는 아직 확인하지 못했다고 명시했다. 이를 근거로 원인을 외부 송신기나 하드웨어로 확정하지 않는다.

[대조용 원본 발췌](../analysis/PERF-PRE-001-MAC-FAIL-excerpt.txt)를 작성했다. CAN 및 receiver 각각 1기준81~87행이며 이상 프레임은84행이다. 두 장비의 현재 프로세스 목록은 참고자료이며, 시험 당시 프로세스 부재를 소급 증명하지 않는다. 식별 전 프로세스를 임의 종료하지 않는다.
