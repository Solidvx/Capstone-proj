## 자료 공유 범위

GitHub에는 소스·시험·경량 보고서·분석표·inventory/해시가 공유된다. `raw/`, 키, 모델, 빌드 산출물, `tmp/`, 개인 `논문작성시_참고자료/`, `실험결과_백업파일/`는 Git 제외다. 클론만으로 raw 기반 분석 전체가 재실행되지는 않는다. 원본 보유자는 BACKUP 문서의 ZIP과 manifest를 별도 전달하고 수신자는 SHA256을 확인한다. Google Drive 백업은 사용자 보고이며 재다운로드 해시는 아직 미확인이다.
