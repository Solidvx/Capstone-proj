# 문서 검토 작업 진입 안내

[루트 SKILL](../../../SKILL.md)의 해당 도메인 플레이북과 [AGENTS](../../../AGENTS.md)를 원본으로 사용한다. 이 문서는 원본의 대체본이 아니다.

[요구사항](../../SRS.md) · [계약](../../ICD.md) · [시험](../../TEST_PLAN.md) · [결정](../../ADR.md)

원천 우선순위에 따라 충돌을 식별한다. 링크뿐 아니라 공식 ID·단계·선행조건·완료 기준을 대조한다. 역사 기록과 현재 안내를 구분하고 검토 범위·근거·미검증을 보고한다. 구조 작업에서는 승인된 참조 수정만 기록하며 본문을 재작성하지 않는다.

[실행 계획](../../../plan/ECU.md) · [IVI 계획](../../../plan/IVI.md) · [공동 연계](../../../plan/detail/common/01_연계_의존성.md) · [작업 기록 안내](../workflow.md)
