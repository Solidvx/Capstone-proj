그림 1 읽는 법

가운데 두 열이 실제 2×20 헤더입니다. 홀수는 왼쪽, 짝수는 오른쪽입니다. 실물 Pin 1을 확인한 뒤 표와 방향을 맞추세요. Pin은 물리 번호, GPIO는 BCM 번호입니다. 표의 좌우 화살표는 목적지를 찾는 방향이며, 실제 신호 방향은 그림 3의 화살표를 따릅니다.

Pin 2(5V) ≠ BCM GPIO2(Pin 3). 전원·GND에는 BCM 번호가 없습니다. B의 화면을 더할 때는 Pin 2·6 분배표도 함께 적용합니다. 각 표는 기판의 연결 관계이며 브레드보드 구멍 좌표가 아닙니다.

그림 2 읽는 법

노브 회전 → OUT 전압 → ADS1115 A0 → I²C → ECU 프로그램 순서입니다. ADS1115와 MCP2515 사이에는 직접 신호선을 잇지 않습니다. ECU가 ADC 값을 읽고 처리한 뒤 SPI를 통해 CAN 메시지를 보냅니다. 실제 I²C 취득과 ECU main 연결은 후속 구현이 필요합니다.

가변저항 VCC와 ADS1115 VDD는 같은 A-3V3 레일입니다. OUT은 0~실제 VDD 이내로 유지하고 노브 양 끝·중간을 측정하세요. SDA/SCL 풀업도 3.3V 기준입니다. ±4.096V는 PGA 측정 범위이지 입력 허용 전압이 아닙니다. 실제 배터리의 30~42V를 A0에 넣지 않습니다. ADS1115가 꺼진 동안 OUT·SDA·SCL만 별도 공급하지 마세요.

분리된 ADS1115 핀헤더는 먼저 납땜하고 인접 핀 단락을 확인합니다. 느슨하게 구멍에 끼운 채 통전하지 않습니다. 그림은 단자명 기준 연결도이며 실제 실크의 VCC·OUT·GND를 우선 확인합니다.

GPIO 신호 연결·통전 전: LC1·LC2의 제품 사양부터 확인하세요.

아래 LV/HV 표는 사진과 같은 핀 이름의 컨버터에 적용하는 연결 경로입니다. 보유품의 정확한 모델·회로·SPI 지원 속도를 확인하기 전에는 Pi와 MCP 사이의 신호 5개를 연결해 통전하지 마세요. “양방향·3.3V↔5V” 표기만으로 SPI 사용 조건이 충족되지는 않습니다. 제품 자료가 없으면 SPI용으로 명시된 변환 모듈을 선정한 뒤 그 제품의 핀표에 맞춰 다시 배선해야 합니다. 다른 칩의 핀 번호에 아래 LV/HV 이름을 그대로 대입하지 마세요.

배선은 같은 작업대의 두 RPi4와 저전압 모듈을 위한 구성입니다. 실차 CAN, 실제 배터리 팩, 12V·24V 전원에는 연결하지 않습니다. 아래 30~42V는 소프트웨어의 가상 배터리 값이며 실제 인가 전압이 아닙니다.

두 노드 공통 연결 조건

LC1은 Pi→MCP 3개와 MCP→Pi 1개의 혼합 방향을 지원해야 합니다. LC2는 INT 한 채널만 사용합니다. GPIO9(MISO)·GPIO25(INT)는 입력으로 사용하고 출력으로 구동하지 않습니다. CS는 비선택 시 HIGH를 유지합니다. SO와 INT를 Pi에 직결하거나 GPIO 쪽에 5V 풀업을 달지 마세요.

각 LC·MCP는 자기 Pi와 함께 켜고 끕니다. 꺼진 쪽으로 신호를 보내 역급전시키지 않습니다. 공급 전압뿐 아니라 컨버터의 부팅/전원 차단 동작·실제 SPI 속도·파형도 확인해야 합니다. SPI 클록을 낮추는 것만으로 안전이나 동작이 보장되지는 않습니다.

그림 4 읽는 법

Pi→레일은 한 번 연결하고, 같은 레일의 서로 다른 구멍에서 목적지마다 선을 나눕니다. A-5V·A-3V3·A-GND·B-5V·B-GND는 별도 구간입니다. 두 노드 사이에는 GND만 연결하며 5V·3.3V 전원끼리는 연결하지 않습니다. 두 GND 단자가 있는 LC는 둘 다 자기 노드의 GND에 연결합니다.

표에 등장한 같은 전원 경로는 반복 설명입니다. 센서표와 전원표를 보고 전원선을 중복 추가하지 마세요. B 화면 전원은 아래 GPIO 분배 경로로 별도 분기합니다.

선 꽂기 전에 준비할 순서
① 양쪽 전원·외부 공급 분리② 레일 분리·납땜 확인③ GND → 전원선 → 신호선④ 무전원 검사 후 단계별 전원 확인
작업확인할 연결진행 조건
브레드보드A-5V / A-3V3 / A-GND / B-5V / B-GND에 이름표를 붙입니다. B의 3.3V는 Pin 1·17에서 각 LV로 갑니다.빈 보드에서 연속성으로 실제 연결 구간을 확인하세요. 같은 5공 묶음에 서로 다른 신호를 꽂지 않습니다. 레일의 중간 단절은 같은 이름끼리만 연결하고, 5V·3.3V·GND 레일끼리는 연결하지 않습니다.
모듈 고정ADS1115의 VDD·GND·SCL·SDA·ADDR·A0 헤더를 납땜하고, 납땜 브리지·노출선·핀 한 칸 밀림을 확인합니다.핀헤더를 구멍에 느슨하게 끼운 채 사용하지 않습니다. 기판 아래에 금속을 놓지 말고, 미사용 단자는 절연·이격합니다.
무전원 검사각 노드의 5V–GND, 3.3V–GND, 5V–3.3V 사이에 배선으로 생긴 단락이 없는지 확인합니다. CAN H–L은 양쪽 종단을 합쳐 약 60Ω입니다.USB-C·전원 있는 USB 주변기기 등 모든 공급원을 분리하세요. 커패시터 때문에 저항값이 변할 수 있으므로 부저 한 번만으로 합격 판정하지 않습니다. 거의 0Ω이 지속되면 원인을 찾기 전 전원을 넣지 않습니다.
전원 확인모듈을 한꺼번에 붙이기 전에 레일 극성부터 확인하고, 매 단계 전원을 분리한 뒤 다음 부품을 연결합니다. 멀티미터는 DC 전압 모드, 검정 리드는 COM, 빨강은 V/Ω 단자입니다.통전 상태에서 Ω/연속성을 측정하지 않습니다. 전류(A/mA) 단자로 전원과 GND를 가로질러 측정하지 않습니다. 프로브로 인접 핀을 잇지 않도록 클립을 무전원에서 고정합니다.

각 Pi는 정상적인 USB-C 공급으로 구동합니다. 외부 5V 공급과 Pi의 5V 출력을 병렬로 묶지 않습니다. 레일의 극성·단락을 확인할 계측기가 없거나 LC 사양이 불명확하면 전원 시험을 진행하지 마세요. 최초 통전은 전류 제한을 사용할 수 있는 시험 환경에서 진행하는 것이 좋으며, 외부 시험 전원을 쓰는 동안에는 해당 모듈의 Pi 전원선·GPIO 신호선을 모두 분리해야 합니다.

전원을 넣은 뒤 확인할 위치

멀티미터 검정은 해당 노드 GND, 빨강은 MCP VCC·LC HV에서 5V 계통, LC LV·ADS VDD에서 3.3V 계통을 확인합니다. TJA1050 정상 공급 범위는 4.75~5.25V입니다. Pi GPIO는 0~3.3V 계통이며 5V를 입력하지 않습니다. 과열·냄새·전압 이상·저전압 경고가 있으면 즉시 전원을 분리합니다. 정적 전압 확인만으로 SPI 파형이나 전체 회로의 안전을 확정할 수 없습니다.

보유한 7인치 Raspberry Pi Touch Display 2에 적용합니다. Node B 40핀 헤더의 Pin 2·6은 위 CAN 전원 배선과 공유합니다. 디스플레이 기본 전원 플러그가 Pin 2·4·6 위치를 차지하므로 먼저 핀 번호가 1:1 대응하는 GPIO 분배 보드/패스스루 헤더를 준비하세요. 분배 부품의 방향·전류 정격·접촉 상태를 확인하고, 한 핀이나 소켓에 커넥터 두 개를 억지로 끼우지 않습니다. 분배 부품은 추가 준비 항목이며 현재 보유가 확인된 것으로 간주하지 않습니다.

무전원에서 잠금 클립을 열고 리본을 끝까지 평행하게 삽입한 뒤 잠급니다. RPi4 쪽 금속 접점은 USB·Ethernet 포트 방향, 디스플레이 쪽은 디스플레이 기판에서 멀어지는 방향입니다. 공식 조립 사진과 대조하세요. CAMERA 커넥터·micro-HDMI·MCP·레벨 컨버터에 이 리본을 연결하지 않습니다.

디스플레이의 J1은 전원 커넥터이고 MCP의 J1은 종단 점퍼입니다. 서로 다른 기판의 이름입니다. 디스플레이 전류가 MCP용 가는 분기선이나 브레드보드를 경유하지 않도록 GPIO 분배에서 제공 전원 케이블로 연결합니다. 화면·팬·CAN을 함께 켰을 때 Pi와 공급 장치의 전체 전력 여유를 확인하고, 전압 강하가 있으면 별도 전원을 임의 병렬 연결하지 말고 전원 구성을 다시 정하세요. Ubuntu에서의 DSI·터치 지원 및 Qt 실행 설정은 대상 OS에서 별도로 확인합니다.

위의 B 전원표·40핀 표는 CAN 경로를 보여줍니다. 화면을 장착하면 같은 Pin 2·6에 이 표의 분기가 추가됩니다. Node A 화면은 기본 구성에 포함하지 않습니다. 추가 팬의 커넥터/정격은 확인 후 별도 매핑하며 사용하지 않는 팬 선을 임의 GPIO에 연결하지 않습니다.

이 배선을 프로젝트 통신으로 연결할 설정

각 MCP의 크리스털 각인을 확인합니다. 제공 사진의 8.000은 8MHz이며, 같은 보드라면 발진 설정은 8000000입니다. 두 실물 모두 확인한 뒤 SPI0·CE0와 interrupt=25(물리 Pin 22 / BCM GPIO25)를 맞춥니다. CAN 버스 속도는 양쪽 500000 bit/s로 일치시킵니다. 이 CAN 속도는 Pi↔MCP의 SPI 클록과 다릅니다.

ECU는 I²C1·ADDR=GND의 0x48과 A0 단일 종단 취득을 사용합니다. 실제 ADS1115 드라이버와 ECU main 연결, 양쪽 can0 생성, ECU 송신·IVI 수신 프로그램이 필요합니다. 현재 기본 코드의 ads1115 모드 선택만으로 실제 I²C를 읽지는 않습니다. H/L 버스는 양방향 전송을 지원하지만, 역방향 애플리케이션 메시지는 ICD에 정의된 송수신 기능과 프로그램이 있어야 합니다. 설정·시험은 공동 통합시험을 따릅니다.

그림 6 읽는 법

두 Pi 전원을 모두 분리하고 GND↔GND → H↔H → L↔L 순으로 연결합니다. 각 MCP의 GND도 자기 노드 GND 레일에 연결돼 있어야 합니다. CAN은 H/H·L/L로 연결하며 UART처럼 교차하지 않습니다.

양 끝의 초록 J1으로 120Ω 종단을 각각 켭니다. 두 저항은 H–L 사이에 놓이며 신호선과 직렬로 연결하지 않습니다. 모든 전원을 분리한 상태에서 H–L 전체 저항은 약 60Ω입니다. 이 값은 종단 확인값이며 전체 회로의 안전 판정값이 아닙니다. USB-CAN을 추가해도 종단은 총 두 개만 유지합니다.

각 Pi는 자기 주변 모듈에 전원을 공급합니다. 외부 전원과 Pi 전원을 같은 레일에 동시에 연결하지 않습니다. CAN 버스는 양방향 전송을 지원하지만 실제 역방향 메시지는 ICD와 프로그램 구현을 따릅니다.
