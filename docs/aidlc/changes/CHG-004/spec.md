# CHG-004 — IVI Qt 현행 안내 정합성

요청: 검토에서 발견한 잔여 Android 기준과 버전 참조를 수정하여 IVI 현행 문서를 Qt 기준으로 통일한다.

- 기준: `chore/ecu-m1-baseline`, HEAD `8907445`. 다른 브랜치에 이미 존재하는 CHG-003과 번호 충돌을 피한다.
- 원본: [ADR-010](../../../ADR.md#adr-010), [IVI 계획](../../../../plan/IVI.md), [Qt 전환 계획](../../../../plan/IVI_PLAN_B_전환계획.md).
- 범위: 루트 작업 지침, ECU/IVI/공동 계획의 현행 진입점, 개발 재개·형상관리·보안 인계 안내, 문서 인덱스.
- 보존: CAN/SecOC/C++ Service 계약, 요구·시험 ID와 합격 기준, 과거 기록, 제품 코드, stash 및 사용자 작업.
- 완료 조건: 현행 안내는 Linux/C++17/SocketCAN/Qt 6 Quick/QML로 연결되고 역사 절차와 구분된다. 변경 링크·펜스·공백 및 보호 파일 보존을 검사한다.
