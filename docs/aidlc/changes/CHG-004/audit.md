# CHG-004 검증 기록

## 판단

Android 과거 문서 자체를 삭제하거나 일괄 치환하지 않았다. IVI 상세 9개 파일의 이전 절차·체크리스트는 역사 자료로 명확히 구분하고 Qt M/P 실행 계획으로 연결했다. 종합 검토의 과거 G/E 표는 역사 경계 아래 보존하되 개발 재개 순서는 현행화했다. 공동 요구 인계의 C++ Service/Qt 경로와 보안 인계의 Linux 권한 확인을 정정했다.

현재 HEAD에는 IVI P1 코드가 없으므로 Qt 구현·빌드 완료로 기록하지 않았다. ICD §8 sensorState는 현행 wire와 분리된 목표라는 기존 경계를 명확히 했다. 새로운 계약이나 시험 기준을 만들지 않았다.

## 검증

- `python tmp/check_qt_docs.py`: 변경/추가 파일 32개, 새로 추가하거나 변경한 상대 링크·앵커 49개 검사, 오류 0건. 변경 Markdown의 코드 펜스 균형 및 IVI 상세 9개 파일의 Qt 진입점 확인.
- `git -c core.safecrlf=false diff --check`: 통과.
- ICD/SRS/TEST_PLAN/ADR 및 adaptive_ecu/security/ivi_platform 변경 없음. 공식 계약·요구·시험 ID와 제품 코드 보존.
- 기존 역사 자료의 모든 링크를 전수 재검증한 결과는 아니다. 검사 범위는 이번 변경 참조이며 과거 날짜별 판단·원문은 적용 경계를 명시해 보존했다.
- 제품 빌드·장비 시험은 문서 변경의 실행 대상이 아니므로 미실행. Qt 구현 완료나 런타임 정합성을 주장하지 않는다. 커밋·push·stash 복원은 수행하지 않았다.

## develop 병합 충돌 해결 — 2026-09-23

AGENTS의 현재 스냅샷은 실제 P1 소스 존재와 CHG-003의 기존 시험 기록을 반영했다. document-map과 path-map은 CHG-003/P1 및 CHG-004 항목을 모두 보존했다. 이전 절의 README만 존재·제품 파일 변경 없음 판정은 문서 정정 당시 HEAD 기준이며 이번 병합 후 상태와 구분한다. P1 제품 파일은 병합 대상 develop과 동일하게 유지한다.
