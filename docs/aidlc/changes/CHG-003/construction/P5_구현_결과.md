# P5 Raspberry Pi 배포·물리 통합 결과

## 상태

- 단계: P5 진행 중
- 대상: Node B Raspberry Pi 4, Debian 13 aarch64, Qt 6.8
- 기록일: 2026-10-03

## 확인된 결과

| 항목 | 결과 | 근거 범위 |
|---|---|---|
| RPi Release Qt 빌드 | 통과 | `build_rpi.sh`가 대시보드 바이너리를 생성했고 Qt 포함 CTest 11/11 통과 결과를 장비에서 확인 |
| 물리 `can0` 준비 | 통과 | MCP2515 `can0`가 500 kbit/s, `UP`, `LOWER_UP`, `ERROR-ACTIVE`인 preflight 출력 확인 |
| SecOC 키 설치 | 통과 | `/etc/ivi/secoc.key`의 32바이트, `0640`, `root:ivi` 조건과 ECU 측 키 해시 일치 확인 |
| DSI 렌더 | 통과 | Touch Display 2에서 Qt Quick 대시보드 실제 출력 확인 |
| 가로 화면 방향 | 통과 | 세로 패널 감지 후 논리 크기 교환과 `-90`도 회전으로 실제 장착 방향 보정 |
| 터치 하드웨어 | 통과 | Debian 데스크톱과 `libinput debug-events`에서 터치 입력 확인 |
| 데스크톱 공존 | 통과 | LightDM을 유지하고 Qt Wayland 플랫폼으로 대시보드 창 실행 및 프로세스 확인 |

## 구현 결과

전용 IVI 모드와 데스크톱 공존 모드를 분리했다.

- 전용 모드: 기존 `ivi-dashboard.service`와 EGLFS를 사용하며 DRM 출력을 직접 점유한다.
- 데스크톱 모드: `install_rpi_desktop.sh`가 XDG 자동 시작 항목을 설치하고, `run_rpi_desktop.sh`가 로그인된 Wayland 세션에서 대시보드를 창으로 실행한다.
- 데스크톱 사용자는 `ivi` 그룹을 통해 SecOC 키를 읽고, 설치된 바이너리는 물리 CAN 수신에 필요한 `CAP_NET_RAW`만 부여받는다.
- 두 모드가 동시에 화면을 점유하지 않도록 데스크톱 설치 시 EGLFS 대시보드 서비스를 비활성화한다.

## 남은 P5 인수

- 재부팅 후 LightDM 로그인과 XDG 자동 시작으로 대시보드가 자동 실행되는지 확인
- Node A가 보낸 실제 BMS·상태·IDS 프레임을 `can0`에서 수신하고 UI 값이 갱신되는지 확인
- 정상·변조·replay·무수신 만료를 물리 CAN과 실제 SecOC 키로 재검증
- CAN 링크 down/up 및 bus-off 복구 확인
- 실제 DSI 표시까지 포함한 T1~T4 지연과 장시간 안정성 기록

위 항목이 남아 있으므로 P5 전체 완료로 판정하지 않는다.
