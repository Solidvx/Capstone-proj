## ViewModel 지연

```bash
/tmp/ivi-p3-final-release/test_dashboard_view_model -v1
```

Release 호스트에서 worker thread→GUI thread property signal 100표본을 측정해 평균 `0.0194079ms`, p99 `0.030958ms`를 기록했다. TC-IVI-008의 호스트 T2→T3 목표 범위는 충족했지만 T1 CAN 수신과 T4 실제 렌더는 포함하지 않는다.

## 화면 상태 smoke

다음 8개 값을 각각 offscreen으로 실행하고 `--demo-screenshot`으로 1100×720 PNG를 생성해 QML 로드, 초기값 숨김, banner, 전체 화면 overlay를 확인했다. PNG는 `/tmp` 임시 검증물이므로 커밋하지 않았다.

## Sanitizer

Qt 타깃을 끈 core 구성에 `-fsanitize=address,undefined -fno-omit-frame-pointer`를 적용했다. 서비스 상태 시험을 포함한 7/7이 2.89초에 통과했다.

## 제한

- macOS에는 Linux SocketCAN과 `vcan0`가 없어 실제 kernel filter·poll/read를 실행하지 않았다.
- offscreen Qt smoke는 QML 로드와 렌더를 확인하지만 실제 RPi4 GPU·터치·HDMI 동작 증거가 아니다.
- sensorState는 ICD §8 wire 전환 전이므로 현행 byte 7을 해석하지 않는다.
- T2→T3 host 지연은 전체 CAN→화면 지연이 아니다.
