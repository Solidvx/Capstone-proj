# P2 빌드·시험 증거

> 실행일: 2026-09-23
> 브랜치: `fix/ivi-secoc-state`
> 호스트: macOS Darwin arm64
> 컴파일러: AppleClang 21.0.0.21000101
> CMake: 4.4.3
> OpenSSL: Homebrew `openssl@3` 3.6.4

## 재현 명령

Debug와 Release 각각 다음 형태로 실행했다.

```bash
cmake -S ivi_platform -B /tmp/ivi-p2-werror-<mode> \
  -DCMAKE_BUILD_TYPE=<Debug|Release> \
  -DIVI_BUILD_QT_APP=OFF \
  -DOPENSSL_ROOT_DIR=/opt/homebrew/opt/openssl@3 \
  -DCMAKE_CXX_FLAGS='-Wall -Wextra -Wpedantic -Werror'
cmake --build /tmp/ivi-p2-werror-<mode> --parallel
ctest --test-dir /tmp/ivi-p2-werror-<mode> --output-on-failure
```

## 확인한 경계

- 다섯 허용 ID와 정확한 DLC 8만 수락
- 미등록 ID, 잘못된 DLC, EFF/RTR/ERR 거부
- signed current와 temperature offset
- HMAC 정상·변조, counter `+1`, `+100`, `+101`, replay, wrap-around
- 인증 전·실패·만료 시 보호값 미갱신과 last-good 보존
- 99ms pending 허용, 100ms 만료
- 같은 ID 최신 원본 교체와 과거 원본 MAC 거부
- orphan auth 폐기, BMS/Fail-safe 교차 순서 독립 처리
- 수신 retry 예산 3회와 성공 후 초기화
- SecOC 연속 4회 실패 WARNING 및 정상 인증 후 연속 횟수 초기화

## 판정과 제한

P2의 플랫폼 독립 core와 정책 시험은 PASS다. macOS에는 Linux SocketCAN/vcan이 없어 실제 `poll/read`, kernel filter와 CAN interface down/up 동작은 실행하지 않았다. 해당 항목은 P4 Linux `vcan0` 증거 없이는 통과로 확대하지 않는다. Qt 화면, stale UI와 물리 CAN도 이 증거의 범위가 아니다.
