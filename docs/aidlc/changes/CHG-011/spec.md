# CHG-011 — ECU ADS1115 제품 연결 (1단계)

요청(2026-10-03): 가변저항 값이 인증된 경로(`0x100` + `0x102`)로 IVI까지 가도록 제품 `adaptive_ecu --sensor-mode ads1115`에 실제 ADS1115 취득을 연결한다. 이전에는 진단 도구만 실제 값을 서명 없이 보냈고, 제품 모드는 고정 42V를 반환했다.

사용자 결정:

- D1=송신 보류: 최초 3회 확인 전, 읽기 실패, 20ms 초과, 결과 지연 중에는 EKF 갱신·Fail-safe 평가·`0x100`/`0x102` 송신을 하지 않는다. 마지막 값을 새 값처럼 보내지 않는다. IVI는 stale로 표시한다.
- D2=A: 전류 -2A, 온도 25°C 가상 고정. 온도 입력용 가변저항 추가(A1)는 후속 확장 후보.
- D3: 복구 뒤 EKF는 공백을 적분하지 않고 마지막 추정값에서 재개한다.
- D4: POTENTIOMETER 모드를 I-5=B에 따라 이관·제거하고 미지원 모드 이름을 오류로 끝낸다.
- D5=B(실장비 시험 후 추가): 0~26400 바깥 허용 폭 이내를 끝점 잡음으로 보고 끝값으로 읽는다. 그 밖은 계속 오류. 처음 ±16코드(약 2mV)로 정했다가 1000회 재측정(최저 -20) 후 사용자 결정으로 **±32코드(약 4mV)**로 넓혔다. 실측 기반 설계값이며 **추가 측정 후 재검토**한다. 근거는 [evidence](evidence.md) §3.
- D6: 오류 상태로 바뀔 때 원인(range+원시값, late+경과 ms, timeout, i2c-start, i2c-read, stale+경과 ms)을 로그에 함께 출력한다. 동작은 바꾸지 않는다.

근거: [SDD-ECU §3.7.3](../../../SDD-ECU.md), [ECU M3 §3.11](../../../../plan/detail/ecu/M3_EKF_Failsafe_SecOC.md), ADC-1/2=A, R-3=A, I-5=B([의사결정 기록](../../../development/governance/의사결정_기록.md)).

제외: ICD 변경(byte 7 센서 상태는 ICD §8 동시 전환 과제), Watchdog 사유 `0x07`, `failsafe_demo.csv`, IVI 통합 시험, ECU 문서의 Debian 13 표기 정리.

완료 조건: 장비 없는 단위 시험 통과와 기존 회귀 유지, ECU RPi에서 노브 변화가 `0x100` 전압에 반영되고 `0x102` MAC이 Python 구현과 일치, 100ms 주기 확인.
