# CHG-005 — 하드웨어 연결 HTML

요청: 처음 조립하는 사람을 위한 HTML을 기존 배선 배치와 실물 자료를 반영해 작성한다.

원본: `하드웨어 정보/컨버터O_배선완결판.html`, shared 사진, 의사결정 기록의 실물 사양, ECU M1/M3 및 공동 통합시험.

산출물: [하드웨어 연결 가이드](../../../development/environment/ECU_IVI_하드웨어_연결가이드.html).

보존 조건: 기존 배치 원본·제품 코드·ICD 불변. J3/J1 오기는 실물 J1로 설명하고 ECU 3.3V 센서 분배를 명시한다. 미확인 SPI 클록·실장비 측정 결과는 추정하지 않는다.

후속 범위: 사용자의 안전성 검토 요청에 따라 Pi/MCP2515/TJA1050/ADS1115 공식 사양과 컨버터 양면 사진을 재대조한다. 기존 핀 경로와 그림 6에서 끝나는 구성을 유지하면서 미확인 컨버터 조건, 전원·접지·역급전·단락·파형 점검과 기능 인수 조건을 보강한다. 실측 없이 안전 보장이나 SPI 적합성 확정을 하지 않는다.

2026-09-25 후속 요청: 현재 HTML을 다시 검토하여 조립 조건과 프로젝트 실행에 필요한 연결을 보완한다. 검토 보고는 HTML에 넣지 않는다. 기존 40핀·CAN 경로는 보존하고 미확인 LC의 통전 제한, ADS1115 헤더·브레드보드 조립, 전원 확인, Touch Display 2의 공유 GPIO 전원과 DSI 연결을 해당 경로 옆에 반영한다. GPIO 분배 부품의 보유/정격과 실제 전기·통신 동작은 확인 전으로 표시한다.

시각화 후속 요청: 기존 배선 원본처럼 다이어그램·표·그림을 먼저 보여주고 설명은 아래에 배치한다. 가변저항→ADS1115→ECU→LC→MCP→CAN→IVI→화면의 전체 흐름과 실제 개별 배선을 구분한다. 물리 Pin과 BCM GPIO를 함께 표기하고 기존 핀 계약·전원 분리·미확인 LC 조건을 보존한다. 그림 6을 마지막 본문으로 유지하며 SVG 렌더와 기계적 핀 대응 검사를 수행한다.
