# 작업 구조 사용 안내

CHG-template은 CHG-<번호>의 구조 템플릿이다. 실제 작업 번호나 진행 중인 과제가 아니다. 담당자끼리 작업 ID를 정한 뒤 복사해 사용하고 unit-template을 실제 작업단위 이름으로 바꾼다. 공유 폴더의 같은 파일을 동시에 편집하는 대신 작업별 기록과 담당 경계를 합의한다.

현재는 목적 안내만 작성했다. 실제 작업을 시작할 때 관련 계획 과제·공식 원본 경로·담당·입력·결과·증거를 기입한다. 비밀이나 실제 자격 증명은 넣지 않는다.
