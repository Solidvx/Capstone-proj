# CHG-022: 공격 노드 분리·새 회로·IDS 유형 정합·1,200회 실행

사용자 요청(2026-10-21): RPi3 공격 노드 분리, ECU/IVI SEENGREAT 220779 각 1개, ECU E3P·Seeed ADS1115 103030279 적용 안내. ECU 의도 공격과 IVI 경보 유형 대조 및 구성별·공격별 1,200회 일괄 실행. 후속 요청: GitHub develop 최신 ECU를 가져와 확인.

기준: ICD 0x200·SecOC, SRS FR-SEC-005/NFR-SEC-003, TEST_PLAN TC-SEC-005/IT-005/TC-EXP, 기존 M5. 계약 변경 없음. 실제 장비 조립·실행은 사용자 담당이며 로컬 시험을 물리 인수로 표시하지 않는다.

계획: 회로·overlay 안내 → 원격 develop과 실제 코드 대조 → 생성 공격/IDS 코드/IVI 표시 시험 → 세 노드 수명 관리·1,200회 계획·집계 → 재현 명령·미검증 범위 기록.

완료 기준: 기존 사용자 변경 보존, 문서 링크 검사, 공격 유형 오분류와 다중 유형의 구별, 미탐/INVALID 보존, 독립 노드의 시각을 직접 빼지 않음, 원본 로그와 코드 버전 보존, 실제 수행 경로의 회귀시험.
