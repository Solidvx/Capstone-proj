# CHG-001 진행 상태

- 작업: [커밋 지침 배치·정합성 정정](spec.md)
- 상태: 완료 — 합의한 문서 배치·충돌 정정·참조 동기화와 정적 검증 완료
- 범위: 기존 커밋 문서와 연결 지침·인덱스·구조 매핑
- 보존 조건: 제품 코드·계약·역사 보관본·기존 사용자 작업 유지
- 현재 환경: `.git` 없음. 브랜치·HEAD 대신 파일 목록과 SHA-256으로 변경 확인
- 검증·한계: [audit](audit.md). 실제 CLI 로딩·GitHub 보호 규칙 동작은 미검증이며 문서 변경 완료와 구분한다.
- 인계: 사람이 수행할 Git/GitHub 작업은 [매뉴얼](../../../development/governance/commit.md), AI의 커밋 검토·실행은 [공통 절차](../../../../.agents/skills/commit/SKILL.md)를 따른다.
